WEBSITE CHÚC MỪNG 20/10 — VŨ NHƯ QUỲNH 💗

NỘI DUNG
- index.html: toàn bộ website, thiết kế responsive cho điện thoại và máy tính.
- Nhạc nền giai điệu tự tạo bằng Web Audio API; không cần tải tệp nhạc riêng.
- Hiệu ứng trái tim/cánh hoa bay, thư tình, nút mở quà và hiệu ứng trái tim.

XEM THỬ TRÊN ĐIỆN THOẠI
1. Giải nén ZIP.
2. Mở index.html bằng trình duyệt Safari/Chrome hoặc chuyển file sang máy tính.
3. Chạm nút “Bật nhạc tình yêu” để cho phép trình duyệt phát nhạc.

CHỈNH SỬA LỜI NHẮN
- Mở index.html bằng trình soạn thảo văn bản.
- Tìm cụm “Gửi Như Quỳnh của anh” hoặc đoạn thư tình để chỉnh nội dung.
- Tên Vũ Như Quỳnh và chữ ký “anh” đã được điền sẵn.

ĐƯA WEBSITE LÊN MẠNG MIỄN PHÍ BẰNG GITHUB PAGES
1. Đăng nhập GitHub và tạo repository mới, ví dụ: 20-10-nhu-quynh.
2. Chọn Public; tạo repository.
3. Chọn Add file → Upload files, tải index.html lên repository (README.txt có thể tải lên thêm).
4. Chọn Commit changes.
5. Vào Settings → Pages.
6. Trong phần Build and deployment, chọn Deploy from a branch.
7. Chọn branch main và folder /(root), bấm Save.
8. Chờ GitHub triển khai; địa chỉ thường có dạng:
   https://TEN-GITHUB.github.io/20-10-nhu-quynh/
   Thay TEN-GITHUB bằng tên tài khoản GitHub của bạn.
9. Mở liên kết trên điện thoại để kiểm tra rồi gửi cho người yêu.

LƯU Ý
- GitHub Pages là hosting tĩnh miễn phí; không cần mua tên miền riêng.
- Có thể mất vài phút để website xuất hiện sau khi bật Pages.
- Nếu không thấy mục Pages, kiểm tra repository đã tạo xong và vào đúng Settings của repository.
- Nhạc chỉ bắt đầu sau khi người xem chạm nút, do giới hạn tự phát âm thanh của trình duyệt.
